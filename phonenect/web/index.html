Приложение для Android: всё автоматически

Приложение само кладёт скопированное на ПК в буфер телефона и отправляет на ПК то, что копируете на телефоне, — без кнопок.

Проще всего — по USB

  1. На телефоне: Настройки → «О телефоне» → 7 раз нажмите «Номер сборки», затем «Для разработчиков» → включите «Отладка по USB».
  2. Подключите телефон кабелем к ПК и в трее Phonenect выберите «Настроить Android по USB». ПК сам установит и подключит приложение.

Или вручную

Скачать приложение

Без настройки по USB буфер телефона уходит на ПК, когда вы открываете приложение.

Быстрые команды для iPhone

Нажмите кнопку: адрес скопируется, а iPhone предложит добавить команду. Когда «Команды» спросят адрес Phonenect, вставьте его (долгое нажатие → «Вставить»).

«На ПК» отправляет буфер iPhone (или то, чем поделились) на компьютер. «С ПК» кладёт буфер компьютера в буфер iPhone.

Жест

Настройки → Универсальный доступ → Касание → Касание задней панели: двойное касание — «На ПК», тройное — «С ПК». При первом запуске разрешите доступ к локальной сети.

Автоматически, без жестов

Открыли приложение — в буфере iPhone уже то, что вы только что скопировали на ПК. Закрыли — скопированное на iPhone ушло на ПК. Работает только в домашнем Wi-Fi, вне дома команды молчат.

При добавлении «Команды» спросят название Wi-Fi: —, а затем адрес (вставьте).

  1. «Команды» → вкладка Автоматизация → + → Приложение. Выберите приложения, где чаще всего вставляете (Telegram, Заметки, Safari…), отметьте «Открыто» и «Выполнять сразу» → команда «Авто — С ПК».
  2. Ещё одна автоматизация: те же приложения, «Закрыто», «Выполнять сразу» → «Авто — На ПК».
  3. Чтобы iPhone не спрашивал разрешения на вставку: Настройки → Приложения → Команды → Вставка из других приложений → Разрешить.

Адрес Phonenect

Собрать команды вручную

«На ПК»: отправить буфер iPhone

  1. Детали команды (ⓘ): включите «Показывать в меню „Поделиться“», типы: изображения, текст, URL. В строке «Если нет входных данных» выберите «Получить буфер обмена».
  2. Добавьте «Получить содержимое URL», вставьте адрес Phonenect. Раскройте параметры: метод POST, тело запроса Файл, файл: Ввод команды.
  3. Добавьте «Показать уведомление» с текстом «Отправлено на ПК».

«С ПК»: забрать буфер компьютера

  1. «Получить содержимое URL» с адресом Phonenect (метод GET, ничего менять не нужно).
  2. «Скопировать в буфер обмена».
  3. «Показать уведомление» с текстом «Скопировано с ПК».
