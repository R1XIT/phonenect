Подключить телефон

Телефон и ПК должны быть в одной сети Wi-Fi.

Android и iPhone: веб-клиент

  1. Наведите камеру телефона на QR-код и откройте ссылку.
  2. Добавьте страницу на главный экран: в Safari «Поделиться → На экран „Домой“», в Chrome «⋮ → Добавить на главный экран».
  3. Всё, что копируется на ПК, появляется на странице; по кнопке «Отправить» текст или фото уходит в буфер ПК.

    Адрес API (с токеном):

    {{API_URL}}

    Команда «На ПК» отправляет буфер iPhone на компьютер:

    1. Детали команды (ⓘ): включите «Показывать в меню „Поделиться“», а в строке «Если нет входных данных» выберите «Получить буфер обмена».
    2. Действие «Получить содержимое URL»: вставьте адрес API, метод POST, тело запроса Файл, файл — Ввод команды.

    Адреса удобнее копировать прямо на iPhone: в веб-клиенте есть раздел «Быстрые команды для iPhone».

    Команда «С ПК» забирает буфер компьютера:

    1. Действие «Получить содержимое URL»: адрес API, метод GET.
    2. Действие «Скопировать в буфер обмена».

    Назначьте команды на жест: Настройки → Универсальный доступ → Касание → Касание задней панели (двойное касание — «На ПК», тройное — «С ПК»). При первом запуске разрешите доступ к локальной сети.

    Android: одно касание

    Приложение HTTP Shortcuts (бесплатное, с открытым кодом): создайте ярлык с методом POST на адрес API, телом запроса сделайте переменную типа «Буфер обмена», тип содержимого text/plain. Для обратного направления: GET на тот же адрес и действие «скопировать ответ в буфер». Ярлыки можно вынести на главный экран или в плитки быстрых настроек.

    Токен хранится в %APPDATA%\phonenect\config.json. Если удалить поле token и перезапустить Phonenect, все подключённые устройства потеряют доступ.
