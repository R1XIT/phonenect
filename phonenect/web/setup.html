Phonenect · {{NAME}}

Шаг 1 из 2: сертификат ПК. С ним телефон узнаёт ваш ПК, и всё, что вы передаёте, шифруется. Делайте это дома: в чужой сети сертификат можно подменить.

iPhone

Скачать профиль

  1. Нажмите «Разрешить», затем Настройки → «Профиль загружен» → Установить.
  2. Настройки → Основные → Об этом устройстве → Доверие сертификатам → включите «Phonenect {{NAME}}».

Android

Приложению сертификат ставить не нужно — оно проверит его само. Скачать приложение.

Только для веб-клиента в браузере: сертификат → Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС.
