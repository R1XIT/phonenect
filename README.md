# Phonenect

Общий буфер обмена между ПК на Windows и телефонами (Android, iPhone) в домашней сети, как Universal Clipboard у Apple.

- Скопировали на ПК — текст или картинка сразу появляются на телефоне.
- Отправили с телефона — это сразу оказывается в буфере Windows, можно жать Ctrl+V.
- Всё работает внутри локальной сети, без облака. Доступ защищён токеном.

## Установка

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Запуск: `start.bat`, иконка появится в трее. Для отладки есть консольный режим:
`.venv\Scripts\python -m phonenect --no-tray`.

**Брандмауэр.** Когда Windows спросит, разрешите Python доступ в **частных** сетях. Сеть Wi-Fi должна быть
отмечена как «Частная» (Параметры → Сеть → свойства Wi-Fi). Если окно не появилось, выполните в PowerShell от
администратора:

```powershell
New-NetFirewallRule -DisplayName Phonenect -Direction Inbound -Protocol TCP -LocalPort 8765 -Action Allow -Profile Private
```

## Подключение телефона

Трей → **«Подключить телефон…»**. Откроется страница с QR-кодом и инструкциями:

| Устройство | Как пользоваться |
|---|---|
| Любое | Веб-клиент по QR-коду: живая лента буфера ПК, отправка текста и фото. Добавьте его на главный экран. |
| iPhone | «Быстрые команды» «На ПК» и «С ПК», повешенные на двойное или тройное касание задней панели. |
| Android | Приложение HTTP Shortcuts: ярлыки и плитки в шторке. |

## Команды для iPhone

Готовые подписанные команды «На ПК» и «С ПК» лежат в `phonenect/web/shortcuts/`. В веб-клиенте они
добавляются кнопками из раздела «Быстрые команды для iPhone». Адрес и токен в команды не зашиты:
iPhone спрашивает адрес при добавлении, а кнопка заранее кладёт его в буфер.

Пересобрать команды после правок: `.venv\Scripts\python tools\build_shortcuts.py`. Скрипт генерирует plist и
подписывает его через [HubSign](https://hubsign.routinehub.services/sign) от RoutineHub, потому что без Mac
подписать команду иначе нельзя. На сервис уходит только шаблон команды, без личных данных.

## API

Авторизация: `?t=<токен>`, заголовок `Authorization: Bearer <токен>` или cookie.

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/clip` | Последний клип «как есть» (`text/plain` или `image/*`) |
| POST | `/api/clip` | Положить в буфер ПК: сырое тело или multipart; тип определяется автоматически |
| GET | `/api/clip/{id}` | Клип из истории |
| GET | `/api/history` | Последние 30 клипов (JSON) |
| WS | `/ws` | События `history` и `clip` в реальном времени |

Имя источника передаётся через `?from=` или заголовок `X-Device`.

## Настройки

`%APPDATA%\phonenect\config.json`:

- `port` — порт (по умолчанию 8765);
- `token` — ключ доступа. Если его удалить, при запуске будет создан новый, и все устройства потеряют доступ;
- `host` — IP для QR-кода. Нужен, если адрес определился неверно, например из-за VPN.

## Ограничения

- Соединение идёт по HTTP внутри локальной сети: токен защищает от посторонних, но трафик не шифруется.
- Браузеры не дают сайтам читать буфер телефона в фоне, поэтому с телефона на ПК отправка идёт по действию:
  кнопка, вставка или жест в «Быстрых командах».
- По http копировать картинку кнопкой нельзя: удерживайте картинку → «Скопировать». Текст копируется кнопкой.
- Если у ПК сменится IP, подключите телефон заново по QR-коду или закрепите адрес в роутере.
