# Phonenect

Общий буфер обмена между ПК на Windows и телефонами (Android, iPhone) в домашней сети, как Universal Clipboard у Apple.

- Скопировали на ПК — текст или картинка сразу появляются на телефоне.
- Отправили с телефона — это сразу оказывается в буфере Windows, можно жать Ctrl+V.
- Файлы и документы любого размера — в обе стороны (см. «Файлы»).
- Несколько ПК: телефон переключается между ними, а сами ПК можно связать в общий буфер.
- Всё работает внутри локальной сети, без облака. Доступ защищён токеном.

## Установка

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Запуск: `start.bat`, иконка появится в трее. Для отладки есть консольный режим:
`.venv\Scripts\python -m phonenect --no-tray`.

**Порты.** 8765 — основной, по HTTPS (всё шифруется сертификатом, который Phonenect выпускает сам). 8766 —
стартовая страница по обычному HTTP: на ней телефон получает сертификат, приложение и команды, секретов там нет.

**Брандмауэр.** Когда Windows спросит, разрешите Python доступ в **частных** сетях. Сеть Wi-Fi должна быть
отмечена как «Частная» (Параметры → Сеть → свойства Wi-Fi). Если окно не появилось, выполните в PowerShell от
администратора:

```powershell
New-NetFirewallRule -DisplayName Phonenect -Direction Inbound -Protocol TCP -LocalPort 8765,8766 -Action Allow -Profile Private
```

## Подключение телефона

Трей → **«Подключить телефон…»**. Откроется страница с QR-кодом и инструкциями. Подключение в два шага:

1. **Стартовая страница** (QR-код `http://…:8766`): с неё телефон ставит приложение и команды, а iPhone и
   браузеры — сертификат Phonenect (на iPhone это профиль; приложению Android сертификат не нужен, оно проверяет
   его само). Здесь же показан отпечаток сертификата.
2. **Подключение** (QR-код `https://…:8765`): телефон открывает защищённый адрес. Android-приложение само
   сверяет отпечаток из ссылки; на iPhone отпечаток виден в сведениях профиля, сверьте его с тем, что показан на ПК.

| Устройство | Как пользоваться |
|---|---|
| Любое | Веб-клиент по QR-коду: живая лента буфера ПК, отправка текста и фото. Добавьте его на главный экран. |
| Android | Приложение Phonenect: синхронизация полностью автоматическая в обе стороны. |
| iPhone | «Быстрые команды»: по жесту (касание задней панели) или сами при открытии и закрытии приложений. |

## Обновление с прошлой версии

Связь теперь только по HTTPS, поэтому после обновления устройства нужно подключить заново:

- **Android**: обновите приложение (по USB через «Настроить Android по USB» или установкой APK) и подключите ПК заново.
- **iPhone**: пройдите шаг 1 (установите профиль) и шаг 2, заново добавьте «Быстрые команды» и ярлык веб-клиента
  на экран «Домой».
- **Связанные ПК**: обновите Phonenect на обоих и свяжите их заново.
- **Брандмауэр**: должны быть открыты порты 8765 (HTTPS) и 8766 (стартовая страница).

## Android: полностью автоматически

Трей → **«Настроить Android по USB»** (на телефоне должна быть включена «Отладка по USB»). ПК сам установит
приложение, выдаст разрешения и подключит его. После этого:

- скопировали на ПК — это сразу в буфере телефона;
- скопировали на телефоне — это сразу в буфере ПК.

Как это устроено. Android 10+ не даёт приложениям читать буфер в фоне. Поэтому приложение с разрешением
`READ_LOGS` (его выдаёт только ADB) ловит в системном журнале момент копирования, на долю секунды открывает
невидимое окно и читает буфер. Так же работают KDE Connect и ClipCascade. Запись в буфер в фоне Android
разрешает, поэтому направление ПК → телефон работает без этого.

Сборка APK: `powershell -File tools\build_android.ps1`. Нужны JDK 21 и Android SDK (по умолчанию ищутся в
`C:\android-toolchain\jdk` и `C:\android-toolchain\sdk`, путь без кириллицы). Готовый APK попадает в
`phonenect/web/android/phonenect.apk`, откуда его ставит «Настроить Android по USB» и раздаёт веб-клиент.

## Файлы

**С ПК на телефон.** Скопируйте файлы в проводнике (Ctrl+C) или выберите в трее «Отправить файлы на телефон…».
Android-приложение само скачивает их в «Загрузки/Phonenect» (файлы больше 200 МБ — по нажатию на уведомление),
в веб-клиенте у файла появляется кнопка «Скачать». Одна скопированная картинка, как и раньше, уходит в буфер
телефона, а не файлом.

**С телефона на ПК.** Android: «Поделиться» → «На ПК» в любом приложении или кнопка «Отправить файлы на ПК» в
Phonenect. iPhone: «Поделиться» → команда «На ПК». Веб-клиент: кнопка «Файл» (на компьютере файлы можно
перетащить на страницу). Файл сохраняется в `Загрузки\Phonenect` и сразу кладётся в буфер Windows как файл:
Ctrl+V в проводнике, Telegram или почте вставит его. Трей → «Открыть полученные файлы».

## Несколько компьютеров

**Телефон и несколько ПК.** Подключите Android-приложение к каждому ПК (QR-код или «Настроить Android по USB»):
новый ПК добавляется в список, а не заменяет прежний. В приложении в разделе «Компьютеры» видно, с каким ПК
сейчас общий буфер; переключение — касанием. Веб-клиент работает с тем ПК, чей QR-код отсканирован.

**Связать два ПК.** На одном ПК: трей → «Связать с другим ПК…», скопируйте адрес. На другом ПК: то же
меню, вставьте адрес → «Связать». Связь работает в обе стороны: скопированное на одном ПК (и пришедшее с его
телефонов) появляется в буфере другого, файлы попадают в его `Загрузки\Phonenect`. Просто скопированные
файлы больше 200 МБ между ПК не передаются, отправленные через «Отправить файлы…» — любого размера. Три ПК и
больше связывайте попарно: клипы не пересылаются дальше по цепочке.

Связь видна на обоих ПК (на втором — как «связан с вами с того ПК») и разрывается кнопкой «Отвязать» с любой
стороны; отвязанный ПК не сможет связаться снова, пока связь не поставят с того ПК, где отвязали. Если у
связанного ПК сменился IP, Phonenect сам найдёт его в сети. Скопированное, пока второй ПК выключен, к нему потом
не досылается. Страница связи открывается только на самом ПК, и запросы к ней с других сайтов отклоняются.

## Команды для iPhone

Готовые подписанные команды лежат в `phonenect/web/shortcuts/` и добавляются кнопками в веб-клиенте
(раздел «Быстрые команды для iPhone»). Адрес и токен в команды не зашиты: iPhone спрашивает адрес при
добавлении, а кнопка заранее кладёт его в буфер.

- «На ПК» / «С ПК» — для жеста касания задней панели и меню «Поделиться».
- «Авто — С ПК» / «Авто — На ПК» — для автоматизаций «При открытии / закрытии приложения». Работают только в
  домашнем Wi-Fi. «Авто — С ПК» забирает буфер ПК, только если он новый и свежий (до 2 минут). «Авто — На ПК»
  не затирает свежий буфер ПК тем, что уже было в истории.

Полностью автоматически на iPhone нельзя: iOS не даёт сторонним приложениям работать с буфером в фоне.

## Пароли из менеджеров паролей

Скопированное из менеджеров паролей (KeePass, Bitwarden, 1Password и других) не синхронизируется: на ПК такое
копирование пропускается (не уходит на телефоны и связанные ПК, не попадает в историю), на Android 13+ приложение
не отправляет помеченный секретным буфер на ПК. На iPhone «Быстрые команды» этого не различают: пароль,
скопированный на iPhone, уйдёт на ПК, если запустить команду.

Пересобрать команды после правок: `.venv\Scripts\python tools\build_shortcuts.py`. Скрипт генерирует plist и
подписывает его через [HubSign](https://hubsign.routinehub.services/sign) от RoutineHub, потому что без Mac
подписать команду иначе нельзя. На сервис уходит только шаблон команды, без личных данных.

## API

Авторизация: `?t=<токен>`, заголовок `Authorization: Bearer <токен>` или cookie.

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/clip` | Последний клип «как есть» (`text/plain` или `image/*`). С `X-Only-New: 1` — только новый для этого устройства и не старше `X-Max-Age` секунд (по умолчанию 120), иначе `204`; файлы так не отдаются |
| POST | `/api/clip` | Положить в буфер ПК: сырое тело или multipart; тип определяется автоматически. Текст и картинки идут в буфер, остальное сохраняется файлом. С `X-Filename` (имя в %-кодировке) или `?name=` — всегда файл. С `X-Auto: 1` уже известное содержимое пропускается (`{"skipped": true}`) |
| GET | `/api/clip/{id}` | Клип из истории; файл отдаётся с `Content-Disposition: attachment` и поддержкой докачки |
| GET | `/api/history` | Последние 30 клипов (JSON) |
| GET | `/api/info` | Имя ПК, его id для поиска в сети и id связанных ПК |
| WS | `/ws` | События `history` и `clip` в реальном времени |

Имя источника передаётся через `?from=` или заголовок `X-Device` (в %-кодировке). Связанный ПК добавляет
`X-Origin` — имя ПК, где клип появился.

## Доверенные сети

Phonenect работает только в сетях, которые вы отметили сами. Сеть определяется по названию Wi-Fi, а без Wi-Fi —
по имени сетевого профиля Windows (например, «Сеть 2»); VPN не учитывается. Отметить текущую сеть можно в меню
значка в трее: «Доверять сети «…»».

В недоверенной сети (например, в кафе) оба порта отвечают всем, кроме самого ПК, ошибкой 403 «Phonenect выключен:
эта сеть не отмечена как доверенная», ПК не объявляется в сети, а связи с другими ПК ждут. Работа с буфером самого
ПК и страница подключения на самом ПК не меняются. Сеть проверяется раз в минуту и сразу после клика в трее. При
первом запуске этой версии текущая сеть становится доверенной автоматически.

## Настройки

`%APPDATA%\phonenect\config.json`:

- `port` — основной порт, HTTPS (по умолчанию 8765);
- `setup_port` — порт стартовой страницы, HTTP (по умолчанию 8766);
- `token` — ключ доступа. Чтобы отозвать доступ у всех устройств (потерялся телефон, ключ кому-то стал известен),
  выберите в трее «Отключить все устройства…»: после подтверждения будет создан новый ключ, а Phonenect
  перезапустится сам. Телефоны и связанные ПК придётся подключить заново (сертификат шифрования не меняется,
  профиль на iPhone переустанавливать не нужно). Android в этом случае покажет «ПК отключил это устройство»;
- `host` — IP для QR-кода. Нужен, если адрес определился неверно, например из-за VPN;
- `name` — имя ПК для телефонов и других ПК (по умолчанию имя компьютера);
- `trusted_networks` — список доверенных сетей (названия Wi-Fi или профили Windows); меняется пунктом в трее;
- `peers` — связанные ПК (управляются со страницы «Связать с другим ПК»);
- `files_dir` — куда сохранять файлы с телефонов (по умолчанию `Загрузки\Phonenect`).

## Ограничения

- Первую настройку телефона делайте дома или в сети, которой доверяете: в чужой сети сертификат можно подменить.
  Всегда сверяйте отпечаток сертификата на телефоне и на ПК.
- В веб-клиенте с телефона на ПК отправка идёт по действию: браузеры не дают сайтам читать буфер в фоне.
- ПК объявляет себя в сети как `phonenect-<id>.local` (своё имя у каждого ПК) и `phonenect.local` (для команд
  iPhone, настроенных раньше), а Android-приложение и связанные ПК находят его сами, так что смена IP им не
  мешает. Веб-клиент по QR-коду привязан к IP: если IP сменился, отсканируйте QR-код заново.
- Android 12+ показывает всплывающее «Phonenect вставил из буфера» при каждой отправке — это системное
  уведомление, отключить его нельзя.
